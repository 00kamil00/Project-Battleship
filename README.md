## 🎯 About

A classic Battleship game built in vanilla JavaScript with a heavy focus on:

* 🧪 **TDD (Test-Driven Development)** using Jest.
* 🏗️ **Clean Architecture** — strict separation between pure game logic and DOM manipulation.
* 🤖 **Smart AI** — an automated computer opponent.

## 🚀 Getting Started Locally

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/00kamil00/Project-Battleship.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd Project-Battleship
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run Jest unit tests:**
   ```bash
   npm test
   ```
